# 調査の共通前提

## 作るもの
Claude Code が Web アプリ・ソフト・サイトを作るときに毎回読み込む、個人用のデザインテンプレート(デザイントークン、コンポーネント規則、UX 規則、禁止事項)。

## 決定済みのコンセプト(2026-11-21)
- 用途: ツール・業務アプリと、個人向けアプリ(習慣・記録など。PWA と Android を含む)
- 印象: 静か + 温かい(Things 3 や iA Writer の静けさに、Airbnb や Headspace の温かさを少し足す)
- 情報密度: 中間を基本にし、トークンで詰める・広げるを切り替えられるようにする
- 配色: ライトとダークを同等に作り、端末の設定に従う
- アクセント色: 苔(落ち着いた緑、#4F6B3A 前後)か琥珀(黄褐色、#9A5B13 前後)のどちらか。未決定
- 角丸: 中くらい(6〜10px)
- 動き: 要所で心地よく(普段は短く、完了や切り替えでわずかに弾む)。prefers-reduced-motion に従う
- 書体: 端末の標準書体(日本語 UI が中心)

## 回答のしかた
- 日本語で答える
- 主張ごとに出典(URL、文献名、著者)を付ける。出典がない主張は「出典なし」と明記する
- 確かさを「確立(研究や公式ガイドラインがある)」「通説(実務で広く使われる)」「意見」の 3 段階で示す
- 具体的な数値(px、ms、比率、OKLCH の値など)があれば必ず書く
- 一般論の羅列ではなく、上のコンセプトに当てはめた推奨を最後にまとめる
